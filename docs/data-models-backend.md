## Doctor

**File:** `backend/app/schemas/doctor.py`

Represents a doctor in the system.

```python
class Doctor(BaseModel):
    name: str
    specialty: str
    availability: bool
    fallback_note: str | None = None
```

| Field | Type | Description |
|---|---|---|
| `name` | string | Doctor's full name (Greek) |
| `specialty` | string | Greek medical specialty (e.g. `Καρδιολογία`) |
| `availability` | boolean | Whether the doctor is currently available for appointments |
| `fallback_note` | string \| null | Present when GP fallback was used instead of matched specialist |

**Static dataset:** `backend/data/doctors.json` — 20 doctors across 15 specialties.

**Specialties in dataset:**
Καρδιολογία, Ορθοπεδική, Νευρολογία, Πνευμονολογία, Γαστρεντερολογία, Γενική Ιατρική, Δερματολογία, Παθολογία, Ουρολογία, Ψυχιατρική, Γυναικολογία, Παιδιατρική, Οφθαλμολογία, Ωτορινολαρυγγολογία, Ενδοκρινολογία, Γενική Χειρουργική

## TriageResponse

**File:** `backend/app/schemas/triage.py`

Response body for `POST /api/v1/triage`.

```python
class TriageResponse(BaseModel):
    mts_level: int
    mts_label: str
    specialty: str
    doctor: Doctor
    reasoning: str
    redirect_url: str
    rag_used: bool = True
```

| Field | Type | Description |
|---|---|---|
| `mts_level` | integer 1–5 | Manchester Triage System urgency level |
| `mts_label` | string | English label: `Immediate`, `Very Urgent`, `Urgent`, `Less Urgent`, `Non-urgent` |
| `specialty` | string | Recommended Greek medical specialty |
| `doctor` | Doctor | Matched doctor (or GP fallback) |
| `reasoning` | string | AI-generated reasoning in Greek |
| `redirect_url` | string | `finddoctors.gov.gr` search URL for the matched doctor/specialty |
| `rag_used` | boolean | `true` if ChromaDB RAG augmented the LLM; `false` if fallback to base knowledge |

**Note on `rag_used = False`:** This flag indicates that ChromaDB was unavailable at the time of the request. The LLM still classified, but without retrieved clinical context.

## QueueEntry

**File:** `backend/app/schemas/triage.py`

Entry appended to the in-memory SSE queue after each successful triage. Streamed to nurse dashboards.

```python
class QueueEntry(BaseModel):
    patient_id: str
    mts_level: int
    specialty: str
    timestamp: str  # ISO 8601, e.g. "2026-04-17T10:30:00+00:00"
```

| Field | Type | Description |
|---|---|---|
| `patient_id` | string | UUID string (generated by patient browser via `crypto.randomUUID()`) |
| `mts_level` | integer 1–5 | MTS urgency level of the triage result |
| `specialty` | string | Recommended specialty (Greek name) |
| `timestamp` | string | ISO 8601 UTC timestamp of when the triage was completed |

**Important:** Only successful triage results are added to the queue. The fail-safe `_SAFE_DEFAULT` response path does **not** append to the queue.

## Doctor Dataset

**File:** `backend/data/doctors.json`

Static JSON array of 20 doctor records. Loaded into memory at startup by `doctor_service.load_doctors()` and indexed by specialty for O(1) matching.

**Dataset summary:**

| Specialty | Count | Available |
|---|---|---|
| Καρδιολογία | 3 | 2 |
| Γενική Ιατρική | 2 | 2 |
| Παθολογία | 2 | 1 |
| All others | 1 each | varies |

**Doctor matching logic (`doctor_service.get_match`):**
1. Find first available doctor in matched specialty
2. If none available → find first available General Practitioner (`Γενική Ιατρική`), set `fallback_note`
3. If no GP available → return unavailable GP placeholder with `fallback_note`
